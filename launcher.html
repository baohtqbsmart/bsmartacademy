How to start it

In a terminal, from the bsmart-academy folder:

npm install          # first time only
copy .env.example .env.local   # then fill in your Supabase URL and publishable key
npm run dev          # serves http://localhost:3000

Signing in needs a Supabase project: a hosted one (values in .env.local) or the local stack (npm run db:start, requires Docker). Without it, pages load but sign-in fails.
